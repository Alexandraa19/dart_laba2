## Ответы на вопросы
1. Поле принадлежит объекту и живёт, пока жив объект. Переменная в функции
существует только во время выполнения функции.
2. Конструктор — специальный метод, вызываемый при создании объекта.
Он инициализирует поля объекта начальными значениями.
3. @override сообщает компилятору, что метод переопределяет метод родителя
(Object). Без него код продолжит работать, но компилятор не проверит
правильность имени — опечатка создаст новый метод вместо переопределения.
4. Статическое поле принадлежит классу целиком, а не отдельным объектам.
В программе существует ровно одна копия статического поля.
5. В Dart _ делает идентификатор приватным для файла (библиотеки).
Обратиться к нему можно только из того же файла
